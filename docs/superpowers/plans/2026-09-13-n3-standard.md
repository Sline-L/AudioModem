# N3 Standard Audio Modem Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained `n3` transmitter and receiver whose wire format matches `Standardization/example_tx.py` while retaining AudioModem's robust synchronization, SFO correction, channel estimation, and diagnostics.

**Architecture:** A small `n3` package separates pure protocol/DSP primitives, a portable adapter around the existing LDPC implementation, frame transmission, synchronization, and frame recovery. The transmitter has one fixed standard profile; the receiver may try multiple timing and SFO candidates but must decode only that profile. Existing N1, N2, archived data, and recorded experiments remain untouched.

**Tech Stack:** Python 3, NumPy, SciPy, standard-library `wave`, `struct`, `zlib`, `json`, `csv`, `unittest`, and the repository's `lib/ldpc` IEEE implementation.

**Spec:** `docs/superpowers/specs/2026-09-13-n3-standard-design.md`

## Global Constraints

- `Standardization/example_tx.py` is authoritative when standard-folder files conflict.
- Use 48000 Hz, FFT size 8192, cyclic prefix 2048, and active bins 400 through 2391 inclusive.
- Use fixed big-endian QPSK with the exact reference mapping; do not expose BPSK, QAM16, uncoded, or alternate-profile transmit modes.
- Use 8 leading and 8 trailing training symbols generated with Python `random.seed(80)`.
- Use identical 3-second linear chirps from 100 Hz to 20000 Hz and 0.5-second silence guards.
- Build one 249-byte `PH` version-0 header block and concatenate it with the payload before padding and coding.
- Use IEEE 802.16 LDPC, rate 1/2, `Z=166`, and reset the `0x5A4D` scrambler for every 3984-bit codeword.
- Never add N2's `AMN2` header, BPSK header symbols, header permutations, extra interleaver, file CRC field, or optional nonstandard modes to N3.
- Do not modify or delete `modem_n2.py`, `tx_n2.py`, `rx_n2.py`, `archive/`, existing recordings, or unrelated untracked files.
- Keep generated N3 files under `data/n3/` and `runs/n3/`.
- Use four-space indentation, `Path` for paths, NumPy vector operations for DSP, and short direct helpers.
- Every implementation task follows red-green-refactor and ends with a focused commit.

```python
N = 8192
CP = 2048

ACTIVE_BINS = np.arange(400, 2392, dtype=int)
INFO_BYTES = 249
CODE_BYTES = 498
TRAINING_SYMBOLS = 8
TRAILING_TRAINING_SYMBOLS = 8
CHIRP_SECONDS = 3.0
SILENCE_SECONDS = 0.5

def header_bytes(name, file_size, payload_symbols):
    encoded = Path(name).name.encode("utf-8")
    if len(encoded) > INFO_BYTES - 16:
        raise ValueError("UTF-8 filename must be at most 233 bytes")
    raw = bytearray(INFO_BYTES)
    raw[:2] = b"PH"
    raw[2] = 0
    raw[3:7] = int(file_size).to_bytes(4, "big")
    raw[7:11] = int(payload_symbols).to_bytes(4, "big")
    raw[11:11 + len(encoded)] = encoded
    crc = zlib.crc32(raw[:11 + len(encoded)])
    raw[12 + len(encoded):16 + len(encoded)] = crc.to_bytes(4, "big")
    return bytes(raw)
```
