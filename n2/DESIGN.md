# OFDM n2 接收端设计方案

本方案只以 [`standard/example_tx.py`](../standard/example_tx.py) 为空中接口真源，独立设计第二版接收机。不读取、不复用 n1 源码与模块划分。发射端文件不得修改。

## 1. 目标与约束

- **兼容**：能解调该发射机生成的 WAV / 播放波形，恢复原文件字节。
- **不拘泥**：同步、信道、均衡、译码调度可以创新，但子载波映射、训练符号、扰码、LDPC、帧头必须与发射端比特级一致。
- **可验证**：理想回环字节一致；帧头 CRC 通过；轻度损伤下恢复成功或给出明确失败阶段。

## 2. 从发射端抽出的空中接口

### 2.1 物理参数

| 参数 | 取值 | 说明 |
|------|------|------|
| `sample_rate` | 48000 | 采样率 Hz |
| `N` | 8192 | FFT 点数 |
| `CP` | 2048 | 循环前缀，符号长 `N+CP=10240` |
| `start_index` | 400 | 正频率数据起始 bin |
| `chunk_size` | 498 | 每符号编码后字节数 |
| 数据子载波 | `[400, 2392)` 共 `4*498=1992` 个 | 每子载波 1 个 QPSK |
| `preamable_count` | 8 | 前/后各 8 个训练符号 |
| 静音 | 0.5 s | Chirp 与 OFDM 体之间 |
| 幅度 | 最终 `0.8 * x / max(x)` | 按整段 OFDM 体峰值归一化 |

### 2.2 帧结构

```
[线性扫频 3.0 s] [静音 0.5 s] [8 训练] [K 个数据符号] [8 训练] [静音 0.5 s] [线性扫频 3.0 s]
```

函数名是 `log_chirp_gen`，但实际相位是线性调频（二次相位），注释掉的对数扫频不得使用。采样网格必须与 TX 相同：

```
t = linspace(0, T, int(fs*T), endpoint=False)
phi = 2π f0 t + π B t² / T
f0=100 Hz, f1=20000 Hz, B=f1-f0, T=3.0 s
```

### 2.3 训练符号

- 频域占用与数据相同的 bin 区间。
- `random.seed(80)`，必须用 **CPython `random.randint`**，不能用 NumPy RNG。
- 每个 bin：`rand_num ∈ {0,1,2,3}`，与数据 QPSK 同一映射——最低位走 I、次低位走 Q：
  `I = 1-2*(rand_num & 1)`，`Q = 1-2*((rand_num >> 1) & 1)`，镜像 `X[N-j]=conj(X[j])`。
- `train_symbol_gen(..., symbol_count=16)`，前 8 个放开头，后 8 个放结尾。

由后训练匹配峰反推 `K` 时：峰在「后 8 训练」的起点，相对体起点的符号数为 `8+K`，因此 `K = round(offset/(N+CP)) - 8`。若用整段体长（含前后训练）则再减 8。不得把训练算进数据符号。

### 2.4 QPSK 映射（接收必须精确求逆）

对编码后的每个 498 字节块、每个字节的 4 个符号（`i = 0 .. 1991`）：

```
d_i = i // 4
b_i = 3 - (i % 4)
I = 1 - 2 * ((byte[d_i] >> (2*b_i    )) & 1)
Q = 1 - 2 * ((byte[d_i] >> (2*b_i + 1)) & 1)
X[start_index + i] = I + 1j*Q
X[N - start_index - i] = conj(X[start_index + i])
```

即每字节从高位对到低位对；每对里 **低位走 I、高位走 Q**。时域：`ifft` 取实部，再把最后 `CP` 点拷到前面。

### 2.5 LDPC 与扰码

编码/译码必须绑定仓库内 [`LDPC/new_ldpc`](../LDPC/new_ldpc/README.md)（Jossy 2018，IEEE 802.16 原型图），**不要**用 PyPI 上同名的量子 `ldpc` 包。

- 调用：`ldpc.code(standard="802.16", rate="1/2", z=chunk_size//3)` → `z=166`。
- 该实现把原型图循环移位取 `proto % z`，**不做** IEEE 文档里的 `floor(p·z/96)` 缩放；n2 必须与之一致。
- `N=24z=3984`，`K=12z=1992` → 信息块 249 字节，码字 498 字节。
- 先 LDPC 编码，再按码字与 LFSR 异或；字节内 **MSB 先入**（`scrambled[8j]` 是该字节 bit7）。
- 译码直接调用该库：`app, it = c.decode(llr, dectype="sumprod2")`。LLR 与库测试相同：`y = 10*(0.5-x)`，即 `L = log P(0)/P(1)`，硬判 `app < 0` → 1。软解调 `L_I ∝ Re(Z)`、`L_Q ∝ Im(Z)`，门控只缩放幅值、不翻符号。
- `z=166` 超出 802.16e 的 `z∈[24,96]`，必须与 TX **同一** `LDPC/new_ldpc` 的 `ldpc.code`，换别的 802.16 库会解不开。
- 使用前按 `LDPC/new_ldpc/README.md` 编译 `src/c_ldpc.c` 到 `bin/`。
- 扰码：15 位 LFSR，种子 `0x5A4D`，输出 bit14，反馈 `bit14 XOR bit13`；**每个码字单独复位**。
- 发射端先把（帧头+文件）补零到 `chunk_size=498` 的整数倍，再按 249 字节切块编码。因此可能出现「多出来的全零信息块」。

### 2.6 PH 帧头（长度 249 字节信息块）

```
[0:2]   魔术数 b'PH'
[2]     版本 0x00
[3:7]   文件字节数 file_size（4 字节，大端）
[7:11]  payloadsymbol 数量（4 字节，大端）——不可作为数据符号数 K
[11:]   UTF-8 文件名
随后 1 字节 0x00（因为 bytearray 初值全零，且 CRC 从文件名后再空 1 字节写入）
其后 4 字节 CRC32（zlib，大端）
其余补 0
```

CRC 覆盖范围：`ba[:11+len(filename)]`，**不含** 结束 `0x00` 与 CRC 本身。

**陷阱**：`header_gen` 里的 `symbol_count = ceil(2*file_size/chunk_size)` 只按文件长度估算码字数，**不含帧头、也不等于 OFDM 数据符号数 K**。接收端必须：

1. 用前后训练间隔得到 K（扣除训练符号，见 2.3）；
2. 载荷取译码信息流的 `[offset+249 : offset+249+file_size]`（整块 249 字节帧头之后），不要从 CRC 字段后面截；
3. 滑动搜到 `b'PH'` 必须以 CRC 通过为唯一确认（文件内容可能碰巧出现 `PH`）；
4. 容忍末尾全零码字。

## 3. n2 接收机架构

与常见「Chirp 相关 → CP 定时 → 线性插值信道 → MMSE+镜像合并」拆法不同，n2 做成四段流水线：

```
WAV
  → 捕获：去斜拍频同步 + 亚采样 Chirp 峰
  → 对准：已知前导二维 (STO, CFO) 网格
  → 信道：频域 Wiener 平滑 + 公共相位跟踪 + 可选 Turbo 回灌
  → 解出：可靠性门控 LLR → 解扰 → LDPC → 滑动 CRC 搜头 → 写文件
```

模块文件（刻意不套 n1 文件名）：

| 文件 | 职责 |
|------|------|
| `params.py` | 与发射端一致的常量 |
| `phy.py` | Chirp 模板、训练再生、QPSK 逆映射、LFSR、PH 解析 |
| `capture.py` | 去斜拍频、Chirp 检测、采样钟粗估 |
| `align.py` | 前导匹配滤波、二维定时/CFO、分数 STO 相位补偿 |
| `channel.py` | LS、Wiener 平滑、CPE/NLMS 跟踪、Turbo 重估 |
| `decode_path.py` | 噪声估计、一致性门控 LLR、LDPC、帧头搜索 |
| `receiver.py` | 编排与诊断 |
| `run_rx.py` | 命令行 |
| `selftest.py` | 回环与损伤 |

## 4. 创新点（均可单独测试）

### I1 去斜拍频同步（Dechirp beat）

本地线性扫频与接收段共轭相乘，残余拍频/残余调频率同时给出 **时延** 与 **采样钟偏**。主峰位置再用三点抛物线插值到亚采样。前后 Chirp 只作确认与粗框 OFDM 体，**不用双峰间距当唯一 SFO 估计**。钟偏用 polyphase / `scipy.signal.resample_poly` 在对准前补偿。

### I2 已知前导的二维 STO–CFO 搜索

用发射端同种子再生的 8 个时域训练符号做匹配滤波。对分数定时假设与小范围 CFO 假设做粗网格，相关能量最大者为锁。主定时 **不以 CP 自相关为第一手段**（CP 仅作旁证）。锁后对每个子载波乘 `exp(-j 2π k Δ / N)` 消分数 STO。

### I3 频域 Wiener 平滑，而不是符号维线性插值 H

对 8 个起始训练做 LS 再沿频率平均，得到 `H_ls[k]`。声学信道频率相干强、带内 SNR 起伏大，用邻域混合而不是缩小 `|H|` 后再 ZF：

```
H_w[k] = w[k] H_ls[k] + (1-w[k]) * 邻域均值
w[k] = |H_ls[k]|² / (|H_ls[k]|² + σ²)
```

`w` 只用于平滑 H，可靠性 `ρ` 只乘到 LLR 幅值。数据段默认 `H_w(start)` 加 I4 跟踪，不把 H 在 K 个符号上做线性插值。

### I4 判决反馈公共相位 + 轻度 NLMS

每个数据符号先 `Z=Y/H` 粗均衡，再在高 SNR 音上估计公共相位，把 `H` 整符号旋转（正频与镜像共轭一致），然后小步长 NLMS 更新 `H[k]`。不要按符号下标对起止训练做每音线性插值。

### I5 Hermitian 一致性门控（不是 MRC 合并）

正频率均衡结果 `Z[k]` 与镜像 `conj(Z_mirror)` 比相位。一致则保留；不一致则把该音 LLR 幅值乘门控系数 `g∈[0,1]`。不把两路当独立观测做 MRC，以免镜像与正频本已线性相关时重复计算。

### I6 空闲 bin 噪声 + 声学可靠性掩膜

`σ²` 用数据带下方保护音（`[1, start_index)`）以及训练残差 `|Y-HX|²`，不用 `[2392, N/2)`（约 14–24 kHz，扬声器常截止，会把噪声估爆）。训练每音残差得到 `ρ[k]`，只缩放 LLR 幅值。

### I7 条件 Turbo 均衡

若首轮 PH 的 CRC 失败，用硬判决重建数据符号当导频再估 H，重出 LLR 再译一轮。CRC 已过则跳过。第二轮若仍无 CRC 通过的头，回退首轮结果。

### I8 滑动 CRC 搜头

解码比特流中搜索 `b'PH'`，按 2.6 校验 CRC。K 只来自同步，载荷长度只来自通过 CRC 的 `file_size`。

## 5. 处理步骤（实现顺序）

1. 读 WAV，int16/float、单声道/多声道（取第一声道）统一成 `[-1,1]` 浮点。
2. 去斜检测第一 Chirp，抛物线亚采样；估计 SFO；必要时重采样。
3. 第一 Chirp 结束 + 静音长度 → OFDM 体粗起点。
4. 二维搜索锁定第一训练符号起点与 CFO；CFO 补偿整段体。
5. 去 CP、FFT；取出数据 bin 与镜像 bin。
6. 起始 8 训练 LS + Wiener；估计 `σ²` 与 `ρ[k]`。
7. 由后训练匹配位置或体长度算 K（不得用帧头 `symbol_count`）。
8. 数据符号：粗均衡 → CPE → NLMS → 一致性门控 → 软 QPSK LLR。
9. 按码字解扰、LDPC。
10. 滑动搜 PH（CRC 确认）；失败则 Turbo 再来一轮，无改进则回退。
11. 写出信息流 `[249 : 249+file_size]` 到恢复的文件名。

分数 STO：匹配滤波给出的 `Δ>0` 表示 FFT 窗相对信号偏晚 `Δ` 样点，补偿 `Y[k] *= exp(-j 2π k Δ / N)`，且只补偿一次、在 LS 之前。CFO 为时域乘 `exp(-j 2π f n / fs)`，补偿后保持复谱，不再取 `.real`。WAV 按 TX 的 `int16/32767` 缩放。

失败时 `diagnostics['stage']` 取 `{capture, align, channel, ldpc, header}` 之一。

## 6. 功能验收

| 用例 | 通过标准 |
|------|----------|
| 理想回环 | 恢复载荷与发射文件逐字节相同 |
| 帧头 | CRC 通过，文件名与 `file_size` 正确 |
| 轻度损伤 | 小延迟和/或 AWGN 下仍恢复，或明确报阶段失败 |

入口：在 `n2` 目录下运行，形式与 n1 相同。

```bash
cd g:\OFDM_gerson\n2
python run_rx.py --wav ..\data\recv.wav --out-dir ..\run\n2\trial1
python selftest.py
```

默认读 `data/` 中的 WAV，结果写到 `run/n2/`；`--out-dir` 可指定 `run/n2` 下自定义子文件夹。若 `source/` 有同名原文件则做字节对照。

创新是否落地（与「整链碰巧回环成功」分开）：

| 编号 | 已实现 | 未实现 |
|------|--------|--------|
| I1 | 去斜/匹配峰抛物线插值；SFO 不单独来自双 Chirp 间距 | 主定时只靠双峰间距 |
| I2 | 关掉 CP 自相关仍能锁第一训练；相关能量随 STO/CFO 网格变 | 锁点来自 CP 峰 |
| I3 | 数据段 H 不做起止训练线性插值；H 沿频率平滑 | `H[k,n]` 按符号线性插值 |
| I4 | 整符号去公共相位，H 小步跟踪 | 无 CPE / 每音独立插值 |
| I5 | 镜像不一致时降低 `\|LLR\|`，均衡不是 `(Z+conj(Z_m))/2` | MRC 合并 |
| I6 | `σ²` 来自保护音或训练残差；深衰音 `\|LLR\|` 更小 | 全音同一噪声且无 `ρ[k]` |
| I7 | CRC 已过则 0 次 Turbo；失败才第二轮，无改进回退 | 无条件双轮或成功仍重估 |
| I8 | 搜 `PH` 且 CRC 范围与 2.6 一致；K 只来自同步 | 用帧头 `symbol_count` 当 K |

## 7. 非目标

- 不修改 `standard/example_tx.py`。
- 不把 n1 的模块、算法或命名搬进 n2。
- 不把帧头 `symbol_count` 当作循环上界。
